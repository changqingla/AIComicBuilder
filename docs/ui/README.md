# 界面预览

工作台采用浅色中性背景、系统字体和统一的顶部导航。项目、剧本、角色、分镜、预览、导入、模型设置和提示词页面使用同一套排版与基础控件。

剧本编辑把构思和大纲放在左侧，把主要空间留给正文；空剧本也可以直接输入并自动保存。分镜列表展示画面和描述，完整编辑在侧边面板中完成，生成设置按需展开。成片和镜头片段在同一个播放器中切换。
